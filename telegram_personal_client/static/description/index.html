Unofficial Telegram Chat

Your personal Telegram account, inside Odoo. Private for each user. Nothing else to install.

Unofficial client. This app is not made by or affiliated with Telegram. It uses the Telegram API to connect each user's own Telegram account.

What it does

  • Each user connects their own account: by scanning a QR code with their phone, or with phone number, login code and two-step password.
  • Chat list with search, unread counts, pinned chats and profile photos.
  • Conversations with private chats and groups: read history (more loads as you scroll), send text, see sent/read ticks.
  • Live: new messages, edits, deletions and read receipts appear by themselves.
  • Contacts: start a chat with anyone in your Telegram address book.
  • Phone-friendly layout inside the Odoo web app.
  • Runs entirely inside Odoo: no extra server, no Docker, no Python package to install. Copy the module, install it, enter your API ID.
  • Administrators see which accounts are connected and can disconnect them (for example when someone leaves the company), without access to anyone's messages.

How it works

  1. The user works in Odoo. Opening a chat, sending a message or scanning the login QR code is an ordinary Odoo request: Odoo checks that the user may do it, then queues the work.
  2. The Telegram engine is a scheduled action that runs inside your Odoo. It keeps one connection per connected account to Telegram's official servers, picks up queued work within about half a second, and receives new messages, edits and read receipts as they happen.
  3. Results are saved in your database, each record visible only to its owner, and pushed instantly to the user's open screen through Odoo's own live-update channel (the same one Odoo Discuss uses).
  4. Sessions are kept (encrypted), so users stay connected across Odoo restarts and upgrades, just like Telegram Desktop.

No message passes through any third-party server: only your Odoo and Telegram.

Private by design

  • Telegram data is visible only to its owner. Other users, Telegram administrators included, cannot read anyone's chats, messages or contacts through Odoo (enforced by record rules, not just hidden in the interface).
  • Telegram sessions are stored encrypted. Set TELEGRAM_SESSION_KEY on your Odoo server and a copy of the database alone cannot open them. Database copies made by Odoo's tools, and neutralized staging databases, drop the sessions.
  • Login codes and passwords are never stored in clear and never written to logs.
  • Disconnecting removes the session from the user's Telegram devices and deletes the cached chats from Odoo. An optional retention period deletes old cached messages automatically.
  • The app collects no data and contacts no server other than Telegram's.

As with any business application, people with direct access to your server or database are outside of Odoo's permission system.

Behaves like a normal Telegram app

Telegram watches accounts that use third-party apps. This app is built to look like a person using Telegram Desktop:

  • Every message is sent by a person clicking Send. There is no bulk messaging, auto-reply, scheduling or member scraping, and the app cannot be used for marketing campaigns.
  • Honest status: users appear online only while the Telegram screen is open, and read receipts are sent only when a chat is actually opened.
  • Telegram's rate limits are respected, and login attempts are capped below Telegram's own limits.
  • One connection per account, kept between sessions: no repeated logins.

Requirements

  • Odoo 19.0. Tested on Odoo 19.0 Community (on-premise, single and multi-worker servers).
  • A free Telegram API ID for your company, from my.telegram.org (API development tools).
  • Outbound internet access from the Odoo server to Telegram.
  • At least 2 cron workers (Odoo's default): the Telegram engine runs as a scheduled action.
  • Not available on Odoo Online (SaaS), which does not allow third-party Python modules.

Setup in four steps

  1. Install the app.
  2. At my.telegram.org, log in with a company phone number, open API development tools and create an app. Note the API ID and API hash.
  3. In Odoo, open Unofficial Telegram › Configuration › Settings and enter them. Recommended: set TELEGRAM_SESSION_KEY in the server environment.
  4. Give users the Unofficial Telegram / User access right. Each user opens the app and connects their own account.

Current limitations

  • Photos, files, voice and video messages are shown as labelled placeholders; open Telegram to view them. Sending them is not supported yet.
  • Broadcast channels, secret chats and calls are not shown.
  • The chat list starts with your 100 most recent chats (archived chats excluded); older chats appear as soon as they receive a message.
  • One Telegram account per Odoo user.
  • Some accounts cannot log in from third-party apps (for example when Telegram requires a login email to be set up first in the official app). The app explains what to do in these cases.
